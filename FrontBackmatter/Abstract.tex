\chapter*{Abstract}
% Short summary of the contents in English\dots a great guide by
% Kent Beck how to write good abstracts can be found here:

Concept-based methods represent a model's computation in terms of
human-meaningful concepts, but they typically encode each concept as a single
scalar coefficient, \eg a unit in the bottleneck of \iacl{CBM}, or an atom in
the dictionary of \iac{SAE}. This scalar encoding trades representational
capacity for simplicity: each concept can vary only in magnitude, so
reconstructing the underlying representation faithfully tends to require many
concepts active at once. This thesis introduces the \ac{VAEE}, a model derived
from first principles that represents each concept as a learned vector embedding
instead, drawing together ideas from \aclp{CEM}, \aclp{VAE}, and \aclp{VQVAE}.
The encoder maps an input to one vector embedding per concept; a learned
prototype for each concept then decides, by similarity, which concepts are
active; finally, the input is reconstructed from the stack of active embeddings. Its
capabilities are demonstrated in one application, the decomposition of \acl{LLM}
activations, where the \ac{VAEE} matches the reconstruction of a parameter-matched
TopK \ac{SAE} using roughly an order of magnitude fewer active concepts ---
evidence that vector-valued concepts carry more information per unit of sparsity. The thesis
is deliberate about the limits of this evidence: reconstruction was assessed
only by \acl{MSE}, each concept now spans several active neurons rather than
one, and the recovered concepts were not found more interpretable than the
\ac{SAE}'s. Its contribution, then, lies in this added representational capacity; the
interpretability of its concepts, their use for steering, and its application to
representation learning more broadly are left for future work.
